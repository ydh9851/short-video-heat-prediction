# 演示脚本（5 分钟答辩）

> 目标：用一条主线证明「数据可信 → 预测可用 → 结论可解释 → 模型可运营 → 系统可工程化」。
> 全程只走已实现的功能，不依赖现场训练模型。

## 1. 演示前准备（提前 10 分钟）

| 检查项 | 动作 | 通过标准 |
|---|---|---|
| 服务 | `docker compose -f deploy\docker-compose.yml ps` 或本地四进程 | 四服务 running / healthy |
| 引擎 | 打开 `/api/predict/engine` | 状态 `UP` |
| 模型 | 预测页提交一次示例 | 3 秒内返回结果（已预热） |
| 数据 | 数据管理页 | 平台列表与样本量正常加载 |
| 浏览器 | 关闭无关标签页，缩放 100% | 页面无横向滚动 |
| 投屏 | 大屏 `/screen/index` 单独窗口 | 分屏或备用标签页已就绪 |
| 账号 | `admin / 123456`（答辩前建议改密） | 可正常登录 |

## 2. 六幕分镜

### 第一幕 0:00–0:25 开场：这个系统解决什么问题

| 项 | 内容 |
|---|---|
| 路由 | `/login` → `/about/index` |
| 操作 | 停在登录页 5 秒（展示数字动效），登录后进入关于页，鼠标划过 hero 六个数字 |
| 话术 | "短视频发布前，创作者只能凭经验判断会不会火。本系统在发布前给出热度预测、等级、区间和可执行建议，并且每个结论都能解释、能复现。" |
| 亮点 | 关于页数字来自实时接口并带本地缓存，不是写死的 |

### 第二幕 0:25–1:10 数据可信

| 项 | 内容 |
|---|---|
| 路由 | `/data/index` → `/analysis/eda` |
| 操作 | ① 数据页展示平台卡片、样本量、质量速览条，点一次「运行质检」；② 切到 EDA「交互洞察」，点击类别柱 → 等级环形图联动 → 散点图随筛选更新；③ 点「重置」 |
| 话术 | "数据来自公开数据集，经统一归一化和 8 项质量门禁；探索页的三张图是联动的——点一个类别，另外两张图跟着变，下面直接给出结论卡。" |
| 亮点 | 交互图与静态图双 Tab；筛选 chips 实时显示样本量与平均热度 |

### 第三幕 1:10–2:10 预测可用

| 项 | 内容 |
|---|---|
| 路由 | `/predict/index` |
| 操作 | ① 拖动粉丝数滑杆到 5 万、发布小时到 20 点；② 选「美食」，提交；③ 读决策卡：结论 / 区间 / 不确定性 / 建议 / 风险；④ 点「计算 90% 区间」 |
| 话术 | "输入只有发布前能拿到的信息，避免泄漏。输出不只是一个数：还有 90% 区间、不确定性等级和两条可执行建议。比如'把发布时间从下午挪到晚间，预期提升约 9%'。" |
| 亮点 | 保形区间与分位数区间并列；结果携带模型版本，便于追溯 |

### 第四幕 2:10–3:00 结论可解释

| 项 | 内容 |
|---|---|
| 路由 | `/attribution/index` |
| 操作 | ① 展示全局 SHAP 重要性；② 用刚才的参数做单样本解释，读 Top-K 贡献与瀑布图；③ 滚到「解释报告」：结论 → 证据 → 建议 → 局限，指出可信度徽标 |
| 话术 | "模型不是黑箱：这一条预测里，粉丝数贡献了多少、发布时间贡献了多少，都拆得开。解释本身也有质量指标——紧凑性、一致性、稳定性，不达标会标黄。" |
| 亮点 | 覆盖率徽标直接显示实测值与 90% 目标的差距 |

### 第五幕 3:00–4:10 模型可运营

| 项 | 内容 |
|---|---|
| 路由 | `/evaluation/index` → `/model/index` |
| 操作 | ① 实验中心选一个模式提交，展示进度条与已耗时，说明是异步任务；② 完成后读一句话结论与 traceId；③ 模型页展示版本/阶段/指标，执行一次「上线预演」，读偏差 P90 与头部重合度 |
| 话术 | "页面上的每个数字都能重跑：实验异步执行、进入台账，traceId 能串到 Python 日志。模型上线前先做预演——候选版本和线上版本在同一批样本上并行打分，偏差超标就不许上线。" |
| 亮点 | 任务状态机 QUEUED→RUNNING→DONE；预演报告落库可回看 |

### 第六幕 4:10–4:50 系统可工程化

| 项 | 内容 |
|---|---|
| 路由 | `/screen/index` → 任意页 |
| 操作 | ① 大屏全屏展示四幕（数据 → 预测 → 归因 → 治理），键盘 ← → 切换；② 回到工作台按 `Ctrl/Cmd + K` 唤起命令面板，输入"归因"回车直达；③ 点顶栏问号启动六步导览，走两步后 Esc 退出 |
| 话术 | "同一套数据可以独立全屏投屏；日常操作有命令面板和导览，答辩演示不需要记菜单。工程侧：43 条后端测试、47 条算法测试全绿，Docker 一条命令拉起四个服务。" |
| 亮点 | 命令面板支持搜索与键盘上下选择；导览高亮当前区域 |

### 收尾 4:50–5:00

| 项 | 内容 |
|---|---|
| 操作 | 回到关于页/工作台 |
| 话术 | "总结：预测只用以发布前可得的信息；结论可解释、可复现；模型可治理、可回滚；系统可一键部署。以上是全部演示，谢谢。" |

## 3. 快捷键与隐藏入口

| 操作 | 效果 |
|---|---|
| `Ctrl / Cmd + K` | 打开 / 关闭命令面板 |
| 命令面板内 `↑` `↓` | 切换候选项 |
| `Enter` | 执行选中命令 |
| `Esc` | 关闭命令面板 / 退出导览 |
| 导览内 `←` `→` | 上一步 / 下一步 |
| 大屏内 `←` `→` | 切换幕 |
| 顶栏放大镜图标 | 命令面板入口 |
| 顶栏问号图标 | 演示导览入口 |

## 4. 应急预案

| 风险 | 现场处理 |
|---|---|
| 引擎未启动、预测变慢 | 提前说明"当前走 CLI 降级通道，约 1 秒"；不要现场重启容器 |
| 实验运行时间过长 | 切到已有台账记录讲结论，说明异步任务不阻塞页面 |
| 图片/图表加载失败 | 切到「静态图组」Tab 或直接讲关于页/大屏 |
| 网络不可用 | 大屏与关于页可离线展示；报告为自包含 HTML 可本地打开 |
| 投屏分辨率异常 | 使用浏览器 100% 缩放 + 全屏（F11），大屏页为 standalone 无侧栏 |
