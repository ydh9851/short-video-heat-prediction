## 5. 接口契约与安全断言

`ApiContractTest` 的 9 条用例对应表：

| 用例 | 断言 | 说明 |
|---|---|---|
| `responseEnvelopeIsStable` | `code/message/response` 三字段 | 所有接口统一响应 |
| `evaluationModesContainNewExperiments` | 实验模式清单包含新增实验 | 防止前端选项与后端脱节 |
| `predictReturnsHeatAndMetrics` | 返回热度、log 值、等级、模型版本 | 预测主链路 |
| `invalidPublishHourIsRejected` | 发布小时越界返回 400 | 参数校验 |
| `engineStatusIsExposed` | 引擎状态接口可读（UP/DEGRADED/DISABLED） | 可观测性 |
| `rawFilesAreListed` | 原始文件清单可读 | 数据接入 |
| `anonymousRequestIsRejected` | 匿名访问业务接口返回 401 | 默认拒绝 |
| `normalUserCannotAccessAdminApi` | 普通用户访问管理接口返回 403 | 最小权限 |
| `ledgerAndMissingTask` | 实验台账可读；不存在的任务返回 404/业务错误 | 异常路径 |

**安全测试结论**（基于上述断言 + 代码审查）：

| 检查项 | 结论 |
|---|---|
| 未登录访问业务接口 | 401，默认拒绝 |
| 普通用户访问 `/api/admin/**` | 403 |
| 密码存储 | BCrypt 单向哈希（`PasswordStorageTest`） |
| 传输敏感字段 | RSA 加密，密文随机（`RSATests`） |
| 分享链接 | 报告分享令牌唯一，未登录只读，不可枚举（`uk_report_share_token`） |
| SQL 注入 | 全部走 MyBatis-Plus 参数绑定，无字符串拼接 SQL |
| 上传文件 | 扩展名白名单（csv/tsv/xlsx/xls/parquet/json），落盘 `data/raw` |

## 6. 性能实测

### 6.1 单条预测（CLI 通道）

在模型已缓存（热态）条件下连续执行 3 次，取中位数：

| 次数 | 耗时 |
|---|---|
| 1 | 1007 ms |
| 2 | 1050 ms |
| 3 | 975 ms |
| **中位** | **1007 ms** |

命令：

```powershell
.venv\Scripts\python.exe algorithm\prediction\predict_api.py --category 美食 --fans 5000 --hour 20 --weekday 5 --month 6
```

口径说明：该数字包含 **Python 解释器启动 + 依赖导入 + 模型加载 + 推理**，属于"每次冷启动进程"的最坏情况；生产默认走常驻 HTTP 引擎，仅进程内推理。项目既有记录（[README](../README.md)「工程能力」表）为常驻引擎约 **11 ms**、CLI 约 **890 ms**，与本次实测的 975~1050 ms 同一量级；常驻引擎不可用时才降级到 CLI 通道。

### 6.2 需在完整环境执行的场景

| 场景 | 命令 | 判定口径 |
|---|---|---|
| 常驻引擎单条 | `POST /api/predict`（引擎 UP） | P50 < 100 ms，P95 < 300 ms |
| 批量 500 条 | `POST /api/predict/batch` | 总耗时与单条均值线性关系，失败条目单独返回 |
| 45 万行导入 | `POST /api/data/import?platform=douyin` | 异步任务，不阻塞其他请求；任务台账可查 `cost_ms` |
| 17 类实验 | `POST /api/evaluation/submit` | 任务状态 QUEUED→RUNNING→DONE，前端轮询不超时 |

> 说明：上述四项依赖完整 Docker/本地服务栈，本机只交付命令与判定口径，不做结论性数字。

## 10. 复现方式

```powershell
# 后端
cd backend
mvn test
Get-ChildItem target\surefire-reports\TEST-*.xml | ForEach-Object {
  $x = [xml](Get-Content $_.FullName); $s = $x.testsuite
  '{0}: tests={1} fail={2} err={3}' -f $s.name, $s.tests, $s.failures, $s.errors
}

# 算法
cd ..
.venv\Scripts\pytest.exe algorithm\tests -q

# 前端（需本机安装 Node.js 18+）
cd frontend
npm install --registry=https://registry.npmmirror.com
npm run build
```
